# 🏦 ATM Banking System

A simple console-based ATM Banking System developed using **Python** and **Object-Oriented Programming (OOP)**.

## 📌 Features

* 🔐 **PIN Authentication** – Verifies the user's PIN before accessing the ATM.
* 💰 **Check Balance** – Displays the current account balance.
* 💵 **Deposit Money** – Allows users to deposit money into their account.
* 💸 **Withdraw Money** – Allows users to withdraw money if sufficient balance is available.
* ⚠️ **Balance Validation** – Prevents withdrawals when the account has insufficient funds.
* ❌ **Input Validation** – Handles invalid amounts and menu choices.
* 🚪 **Exit ATM** – Allows users to safely exit the ATM system.

## ▶️ How to Run

### Using Google Colab

1. Download or clone this repository.
2. Open `atm-banking-system.ipynb` using **Google Colab**.
3. Run the notebook cells in order.
4. Enter the required PIN and follow the ATM menu.

### Using Jupyter Notebook

Open the notebook using Jupyter Notebook or JupyterLab and run the cells in order.
